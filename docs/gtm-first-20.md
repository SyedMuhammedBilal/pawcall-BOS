## Outreach sequence

1. **Day 1:** ask for feedback, not adoption: “I’m launching a tiny open-source CLI that turns vet appointment CSVs into tomorrow’s reminder-call list. Would you sanity-check whether this matches how clinics actually run reminders?”
2. **Day 3:** share README and a sample CSV/output screenshot.
3. **Day 7:** ask for one of three actions: sample export schema, 15-minute workflow call, or permission to notify them when the repo goes public.
4. **After 3 feedback calls:** update CSV mapping issue and README before public launch.

## What not to do yet

- Do not email a broad list.
- Do not claim PMS integrations.
- Do not ask clinics to upload real patient/client data.
- Do not promise hosted reminders or automated calls.
