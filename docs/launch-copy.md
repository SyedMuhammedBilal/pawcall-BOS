## LinkedIn launch post

Vet clinics lose too much time figuring out who needs a reminder call tomorrow, especially when appointments span locations or time zones.

This week we’re launching **pawcall**, a tiny open-source TypeScript CLI that reads a CSV of clinic appointments and prints which pet owners need reminder calls tomorrow, grouped by the clinic’s time zone.

It is intentionally small:
- CSV in
- tomorrow’s reminder-call list out
- grouped by timezone and clinic
- unit tested
- GitHub Actions CI included

The first version is for operators and builders who still move appointment data around in spreadsheets and want a simple, auditable workflow before anything gets fancy.

If you work with veterinary clinics and want to try it, the repo is private for now while we polish the first release.
